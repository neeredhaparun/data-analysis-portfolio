# Data Visualization with Python

This repository contains a collection of Jupyter Notebooks demonstrating various data visualization techniques using **Python**, **Pandas**, and **Matplotlib**. The notebooks were completed as part of IBM's Data Visualization labs and use developer survey datasets to explore trends, distributions, comparisons, and relationships within the data.

## Repository Contents

| Notebook | Description |
|----------|-------------|
| 📊 Data_Visualisation_Bar_Charts.ipynb | Visualizing categorical data using bar charts and grouped bar charts. |
| 📈 Data_Visualization_Histogram.ipynb | Exploring numerical data distributions using histograms. |
| 📦 Data_Visualisation_Box_Plot.ipynb | Analyzing distributions, medians, quartiles, and outliers using box plots. |
| 🔵 Data_Visualisation_Bubble_Plots.ipynb | Visualizing relationships among multiple variables using bubble plots. |
| 📉 Data_Visualisation_Line_Charts.ipynb | Displaying trends and comparisons using line charts. |
| 🥧 Data_Visualisation_Pie_Charts.ipynb | Showing proportions and composition using pie charts. |
| ⚫ Data_Visualisation_Scatter_Plot.ipynb | Examining correlations between variables using scatter plots. |
| 📚 Data_Visualisation_Stacked_Charts.ipynb | Comparing multiple categories using stacked bar charts. |

- Platforms
- Developer Roles
- Work Preferences
