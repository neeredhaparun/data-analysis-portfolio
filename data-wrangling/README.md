# Data Wrangling with Python

## Overview

This project demonstrates essential data wrangling techniques used to prepare raw survey data for analysis. The workflow focuses on exploring the dataset, identifying data quality issues, cleaning inconsistent values, handling missing data, encoding categorical variables, and transforming numerical features.

## Objectives

- Load and explore a real-world survey dataset
- Inspect data types and summary statistics
- Identify inconsistent or irrelevant entries
- Standardize categorical values
- Handle missing values using appropriate imputation techniques
- Apply one-hot encoding to categorical variables
- Normalize numerical data using Min-Max Scaling
- Reduce skewness using log transformation

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib

## Data Wrangling Techniques

- Data exploration and profiling
- Missing value analysis
- Mean, median, and mode imputation
- Data standardization
- One-hot encoding
- Feature scaling (Min-Max Scaling)
- Log transformation

## Files

- `DataWrangling.ipynb` – Complete notebook containing data exploration, cleaning, preprocessing, and feature transformation.

## Key Learning Outcomes

Through this project, I gained practical experience in preparing real-world datasets for analysis by:

- Exploring dataset structure and identifying data quality issues
- Cleaning inconsistent and missing data
- Transforming categorical variables into machine-readable format
- Scaling and transforming numerical features
- Building a clean dataset suitable for visualization and machine learning
