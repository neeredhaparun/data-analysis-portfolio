# Exploratory Data Analysis (EDA)

## Overview

This folder contains a collection of exploratory data analysis (EDA) projects performed on survey datasets using Python. The notebooks demonstrate techniques for understanding dataset structure, identifying data quality issues, analyzing variable relationships, and visualizing distributions before building predictive models or performing advanced analytics.

## Topics Covered

- Data exploration and summary statistics
- Missing value analysis and handling
- Distribution analysis of numerical and categorical variables
- Outlier detection
- Correlation analysis
- Exploratory visualizations using Matplotlib and Seaborn

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Notebooks

### Exploratory_Data_Analysis.ipynb
Performs an exploratory analysis of a survey dataset by:
- Inspecting the dataset structure
- Handling missing values
- Analyzing employment status and job satisfaction
- Exploring remote work trends
- Investigating programming language usage by region
- Examining relationships between education, experience, and employment

### Finding_How_The_Data_is_Distributed.ipynb
Explores the distribution of dataset features using:
- Histograms
- Box plots
- Frequency distributions
- Distribution comparisons

### Finding_Outliers.ipynb
Identifies and analyzes outliers using:
- Box plots
- Interquartile Range (IQR)
- Descriptive statistics

### Finding_Correlation.ipynb
Examines relationships between variables through:
- Correlation matrices
- Scatter plots
- Correlation coefficients

## Key Learning Outcomes

Through these projects, I gained hands-on experience in:

- Performing exploratory data analysis on real-world datasets
- Identifying missing values and outliers
- Understanding feature distributions
- Measuring relationships between variables
- Creating effective visualizations to communicate insights
